# netly-profile

Зона ответственности: аутентификация, онбординг, источники дохода, обязательные расходы.

Фреймворк: Vapor. Порт по умолчанию: 8081.

## Запуск

```bash
swift run
```

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/health` | Проверка работоспособности сервиса |

Пример ответа:

```json
{ "status": "ok", "service": "netly-profile" }
```
