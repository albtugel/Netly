# netly-savings

Зона ответственности: накопительные цели, распределение остатка, уведомления.

Фреймворк: Hummingbird. Порт по умолчанию: 8083.

## Запуск

```bash
swift run
```

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/health` | Проверка работоспособности сервиса |

Пример ответа:

```json
{ "status": "ok", "service": "netly-savings" }
```
