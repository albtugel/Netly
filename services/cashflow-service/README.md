# netly-cashflow

Зона ответственности: подписки, задолженности, расчёт денежного потока.

Фреймворк: Vapor + Queues. Порт по умолчанию: 8082.

## Запуск

```bash
swift run
```

## Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/health` | Проверка работоспособности сервиса |

Пример ответа:

```json
{ "status": "ok", "service": "netly-cashflow" }
```
